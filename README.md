# もちもちリンク / Mochi Mingle

和菓子モチーフの3マッチパズル。スマホでもPCでも、ブラウザだけで遊べます。

**▶ あそぶ: https://monkey-mountain.github.io/mochi-mingle/**


---

## これは何？

となりどうしの和菓子を入れかえて、たて・よこに3つ以上そろえて消す落ちものパズルです。
全12ステージ。ステージごとに目標（スコア／味をあつめる／きなこを払う／こおりを割る）と
手数が決まっていて、手数内に全部の目標を達成するとクリア。スコアに応じて★が最大3つもらえます。

- **フレームワークなし** — HTML + CSS + バニラJS（ES Modules）のみ。ビルド不要
- **スマホ対応** — スワイプ／2回タップ操作、セーフエリア対応、ホーム画面に追加可能（PWA manifest）
- **音も自前** — WebAudioで合成。音声ファイルは1つも使っていません
- **進捗保存** — localStorage に★とクリア状況を保存

### ゲームの要素

| 要素 | 内容 |
| --- | --- |
| ながし | よこに4つそろえると出現。よこ一列を一掃 |
| たきつぼ | たてに4つそろえると出現。たて一列を一掃 |
| ぽんっ | L字・T字にそろえると出現。まわり3×3を爆発 |
| ほしだいふく | 5つそろえると出現。入れかえた相手と同じ味を全部消す |
| きなこ | 盤面にかかった粉。その上で和菓子を消すと払える（二重は2回） |
| こおり | 中の和菓子は動かせない。巻きこんで消すと割れる |
| かべ | 和菓子が入らないマス。落下もさえぎる |

特殊な和菓子どうしを入れかえると、十字・大十字・5×5・全消しなどの組み合わせ技になります。
連鎖するほどスコア倍率が上がります。

## 遊び方（ローカル）

ES Modules を使っているので、`file://` ではなく簡易サーバー経由で開いてください。

```bash
python3 -m http.server 4173
```

→ ブラウザで http://localhost:4173 を開く

## 構成

```
index.html                画面とSVGスプライト（和菓子のアートはすべてインラインSVG）
css/style.css             全スタイル
js/engine.js              ゲームロジック（DOM非依存）。マッチ判定・特殊生成・連鎖・重力
js/levels.js              全12ステージの盤面・目標・★しきい値
js/ui.js                  描画・入力・画面遷移。engineの状態とDOMを差分更新
js/audio.js               WebAudioによる効果音
js/main.js                エントリポイント
tools/simulate.mjs        自動プレイによる不変条件テスト
tools/balance.mjs         難易度レポート（勝率・スコア分布）
```

`engine.js` は描画を一切知りません。`resolve()` がジェネレータで、
盤面を1フェーズずつ進めながら yield するので、UI側はそのたびに差分描画して
CSSトランジションでアニメーションさせています。

## 開発用ツール

```bash
node tools/simulate.mjs 40    # 全ステージ×40回ランダム自動プレイ＋盤面の不変条件チェック
node tools/balance.mjs 80     # 貪欲プレイヤーで勝率とスコア分布を測定
```

ステージの手数・目標量・★しきい値は、この `balance.mjs` の測定結果をもとに決めています
（貪欲プレイヤーでの勝率がだいたい 95% → 45% になだらかに下がるよう調整）。

## オリジナル作品についての注記

本作は既存のマッチ3ゲームに着想を得たオリジナル作品です。

- 名称・ロゴ・キャラクター・UI文言・ステージ構成・配色は独自のもの
- 画像・音声を含むすべてのアセットは本リポジトリ内で生成（インラインSVG／WebAudio合成）
- 既存ゲームの素材、名称、コードは一切使用していません

マッチ3というジャンルの基本ルール自体は、多数のゲームが共有する一般的な遊び方です。
